## 深读项目

### 项目 1: colbymchenry/codegraph

- **一句话判断**: 通过预索引代码知识图谱让 AI Agent 减少 90%+ tool call 和 70%+ 时间，是 AI coding 工具链中 token 成本优化的里程碑项目
- **解决的问题**: 替代了 Claude Code/Cursor 等 Explore agent 反复用 grep/find/Read 扫描文件的高消耗做法，将代码结构预先抽取为图谱，一次查询返回完整上下文
- **架构/实现**: 
  - ** Extraction 层**: tree-sitter 解析源码为 AST，通过语言特定 query 提取 nodes（函数/类/方法）和 edges（调用/导入/继承）
  - ** Storage 层**: 本地 SQLite（`.codegraph/codegraph.db`）+ FTS5 全文搜索，所有数据不离开机器
  - ** Resolution 层**: 提取后解析引用关系（函数调用→定义、import→源文件、类继承、框架特定路由）
  - ** Auto-Sync 层**: MCP server 用 OS 原生文件事件（FSEvents/inotify/ReadDirectoryChangesW）监控，2 秒 debounce 后增量同步
  - ** MCP Server 工具集**: codegraph_search/callers/callees/impact/node/context/files/status
- **可复用经验**: 
  - 当需要让 AI 高效理解大型代码库时，应优先构建代码结构图谱而非直接让 AI 扫描文件系统，图谱查询一次返回所有相关上下文
  - 当 AI tool call 成为 token 瓶颈时，应优先实现预索引+轻量查询分离架构，将 discovery 和 detail 分层处理
- **可尝试实验**: 选一个自己的项目，运行 `npx @colbymchenry/codegraph init`，对比 Agent 在同一个探索任务上的 tool call 次数和耗时
- **风险边界**: License: MIT，可商用；数据全本地，无外传风险；项目较新（2026-01），维护活跃度高但 issue 有 47 个，部分边界 case 还在修复中

### 项目 2: microsoft/ai-agents-for-beginners

- **一句话判断**: 微软出品的最系统的 AI Agent 入门课程，12 节课程覆盖从概念到生产环境，是目前最完整的 Agent 学习路径之一
- **解决的问题**: 替代了零散的博客和文档，提供从理论（设计模式）到框架（Microsoft Agent Framework/Azure AI Foundry）到实战的完整学习闭环
- **架构/实现**:
  - ** 12 节课程结构**: Intro→框架→设计模式→Tool Use→Agentic RAG→Trustworthy→Planning→Multi-Agent→Metacognition→Production→协议(MCP/A2A)→Context Engineering→Memory
  - ** 代码样例**: `code_samples/` 文件夹，基于 Microsoft Agent Framework + Azure AI Foundry Agent Service V2
  - ** 多框架覆盖**: Microsoft Agent Framework (MAF)、Azure AI Foundry Agent Service V2，也支持 OpenAI-compatible providers（如 MiniMax 204K 上下文）
  - ** 多语言支持**: 50+ 语言翻译，含简体中文
- **可复用经验**:
  - 当设计一个技术课程时，应优先采用「概念→框架→模式→生产」的结构，而非按工具分章节，这样学员能形成完整心智模型
  - 当学习 AI Agent 新技术时，应优先选择有配套代码样例 + 视频 + 多语言翻译的系统性课程，而非零散博客
- **可尝试实验**: 挑选 Lesson 4（Tool Use）或 Lesson 7（Planning）运行代码样例，体会 Agent 框架的基本调用模式
- **风险边界**: License: MIT，可商用；Microsoft 官方维护，活跃度高；唯一依赖 Azure AI Foundry（需要账号），纯离线学习受限制

### 项目 3: KeygraphHQ/shannon

- **一句话判断**: 将静态代码分析（SAST）和动态渗透测试结合的 AI 自动渗透测试工具，每个漏洞都有可复现的 PoC，是 DevSecOps 中填补 CI/CD 安全缺口的有力武器
- **解决的问题**: 替代了传统的一年一次渗透测试，用 AI 驱动的持续自动化安全测试，在每次 build/release 时自动运行
- **架构/实现**:
  - ** 两阶段架构**: (1) Agentic Static Analysis 构建代码属性图（CPG）进行数据流分析 + 业务逻辑安全测试；(2) Autonomous Dynamic Pentest 动态执行真实漏洞利用
  - ** 静态-动态关联**: 静态发现的漏洞（如未过滤输入→SQL 查询）会被注入对应 Exploit Agent，在运行应用上尝试真实 PoC，确认后才上报
  - ** Shannon Pro 额外能力**: SAST + SCA + 秘钥检测 + 业务逻辑安全测试，CPG-based data flow + LLM reasoning at every node
  - ** 部署模型**: 支持 self-hosted runner（代码不离开客户网络）+ Keygraph control plane（只接收聚合发现）
  - ** 支持特性**: 并行处理、TOTP/2FA 自动处理、工作空间恢复（checkpoint via git commits）、多 AI Provider（Anthropic/AWS Bedrock/Google Vertex）
- **可复用经验**:
  - 当需要进行代码安全测试时，应优先选择静态分析和动态测试相结合的方案，单独任何一种都有盲区
  - 当 AI Agent 执行敏感操作（如漏洞利用）时，应优先设计工作空间恢复机制，使中断后可从断点继续而非重新开始
- **可尝试实验**: 用 `npx @keygraph/shannon start -u https://example.com -r /path/to/repo` 对一个本地测试应用（如 OWASP Juice Shop）运行一次完整渗透测试，观察报告输出
- **风险边界**: License: AGPL-3.0（Shannon Lite 限本地测试）；Shannon Pro 商业授权；Warning：工具会主动执行漏洞利用，必须有系统所有者的书面授权才可使用

## 经验沉淀

1. **预索引是 AI coding 工具的下一个优化方向**: codegraph 通过预建知识图谱将探索 agent 的 tool call 减少 90%+，这在 context window 越来越贵、token 成本压力增大的背景下会成为标配。类似思路可以迁移到其他场景（如文档搜索、API 理解）。
2. **Agent 开发正在从「框架选型」走向「工程化落地」**: 学习的重心已从「用哪个框架」转移到「怎么做监控、怎么做安全、怎么做 memory、怎么做评估」，agents-towards-production 的 28 个 tutorial 覆盖了这些工程化环节，值得系统刷一遍。
3. **安全测试正在被 AI 重新定义**: Shannon 的「白盒静态分析 + 动态验证联动」模式将安全测试从专业安全工程师的专属能力变成了 CI/CD 中的自动化步骤，这一趋势会加速 DevSecOps 落地。
4. **GitHub Trending 是发现早期趋势的好地方**: codegraph（2026-01 建 repo）857 stars/day、Open-Generative-AI 703 stars/day，都是早期快速起量的项目，及时关注可以捕获技术浪潮的前沿。
5. **可复原性设计降低成本**: Shannon 的工作空间+git checkpoint 机制、codegraph 的增量 sync，说明好的 agent 系统需要将「可中断、可恢复」作为核心设计原则，而非附加功能。
