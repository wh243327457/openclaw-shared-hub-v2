## C. 深读项目：rohitg00/agentmemory

> **选读理由**：今日Trending第2位，1,048⭐日增量，专注解决AI编码Agent的长期记忆痛点，内建OpenClaw官方集成，技能可迁移性高。

### README 核心命令

```bash
# 方式一：npx 一键启动（最简）
npx @agentmemory/agentmemory

# 方式二：源码构建
git clone https://github.com/rohitg00/agentmemory.git && cd agentmemory
npm install && npm run build && npm start

# Demo模式：播种示例数据并验证语义检索
npx @agentmemory/agentmemory demo
# 效果：输入"N+1 query fix"，语义匹配找到"database performance optimization"——关键词匹配无法做到

# OpenClaw 集成配置
# 在 OpenClaw MCP config（~/.openclaw/mcp.json）添加：
{
  "mcpServers": {
    "agentmemory": {
      "command": "npx",
      "args": ["-y", "@agentmemory/mcp"],
      "env": {
        "AGENTMEMORY_URL": "http://localhost:3111"
      }
    }
  }
}
# 重启 OpenClaw，验证：curl http://localhost:3111/agentmemory/health
# 实时查看器：http://localhost:3113

# Codex 插件安装
codex plugin marketplace add rohitg00/agentmemory
codex plugin install agentmemory
```

**检索架构**：BM25 + Vector（all-MiniLM-L6-v2本地嵌入）+ Graph，RRF融合，4层记忆巩固 + decay + auto-forget

### 可迁移设计模式

1. **MCP Server 跨Agent统一配置**：同一个 `mcpServers.agentmemory` block 可直接 paste 到 Cursor/Claude Desktop/Cline/Windsurf/Gemini CLI/OpenClaw 的配置中，无需修改——证明了"平台无关MCP配置块"的可移植性，OpenClaw Skill 制作可直接参考此模式
2. **12-Hook 自动记忆捕获**：SessionStart→UserPromptSubmit→PreToolUse→PostToolUse→PreCompact→Stop 覆盖完整对话生命周期，无需人工 add() 调用，适合 OpenClaw 的 HEARTBEAT 机制增强
3. **BM25+Vector+Graph RRF 混合检索**：解决了"关键词查不到语义相关"的问题，适合增强 memory_search 的检索质量
4. **iii Engine 解耦**：记忆引擎与具体 Agent 解耦，通过 MCP / REST 协议通信，多 Agent 共享同一记忆服务器

### 风险边界

- **iii-engine 版本锁定**：agentmemory 当前 pin iii-engine v0.11.2，v0.11.6 引入 sandbox 新模型尚未适配，有版本升级风险
- **localhost:3111 依赖**：需在独立终端运行 memory server，AGENTMEMORY_URL 依赖本地服务可用性
- **Sandboxed 环境限制**：Flatpak/Snap 等受限容器需设置 `AGENTMEMORY_FORCE_PROXY=1` 并指向 LAN IP
- **许可证混淆**：repo license 字段返回 "Other"，需确认实际 LICENSE 文件（README 提到 Apache-2.0 或需核实）
