## 3. 复核时新增的 1 个观察

在复核过程中注意到一个**模式**（不是新增事实）：

> **当 cron 跨日触发 + 父 run 完整完成时，应优先采用「幂等复核 + 增量留痕」模式**，而不是「无脑重做」。
>
> **原因**：每次全量重做消耗 30k+ tokens、可能覆盖更优内容、且容易引入版本漂移（父报告 stars 是 2026-06-10T23:46 的，新跑会是 00:30 的，但都是当日）。
>
> **边界**：仅当父 run 距今 < 6h 且 trace 表完整时适用；超过 6h 或 trace 不全，必须全量重跑。

这条观察在 lessons.md 追加为 #90。
