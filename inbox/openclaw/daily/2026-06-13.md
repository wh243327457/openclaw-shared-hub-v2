### 1. NVIDIA/SkillSpector

**一句话判断**: AI Agent skill 安全扫描的行业标准工具——对任何使用 Claude Code / Codex CLI 的团队都是必备。

**解决的问题**: AI agent skill 以隐式信任执行，研究显示 26.1% 含漏洞、5.2% 有恶意意图。SkillSpector 用自动化静态+LLM 分析替代人工安全审查，填补了 SAST 工具无法覆盖 prompt injection、MCP poisoning 的空白。

**架构/实现**:
```
CLI (typer) → LangGraph StateGraph workflow:
  resolve_input → build_context → [16 parallel analyzers] → meta_analyzer → report

分析器分类:
  - Static pattern matchers (10): regex-based, 快速扫描
  - Behavioral analyzers (2): AST 分析, taint tracking
  - Semantic analyzers (3): LLM 驱动 intent/quality/discovery
  - MCP analyzers (3): least privilege, rug pull, tool poisoning
  - YARA signatures: 恶意软件模式匹配
```

```python
def create_graph():
    workflow = StateGraph(SkillspectorState)
    workflow.add_node("resolve_input", resolve_input)
    workflow.add_node("build_context", build_context)
    workflow.add_node("meta_analyzer", meta_analyzer)
    workflow.add_node("report", report)
    for analyzer_id in ANALYZER_NODE_IDS:
        workflow.add_node(analyzer_id, ANALYZER_NODES[analyzer_id])
    workflow.add_edge(START, "resolve_input")
    workflow.add_edge("resolve_input", "build_context")
    for analyzer_id in ANALYZER_NODE_IDS:
        workflow.add_edge("build_context", analyzer_id)
        workflow.add_edge(analyzer_id, "meta_analyzer")
    workflow.add_edge("meta_analyzer", "report")
    workflow.add_edge("report", END)
    return workflow.compile()
```

```python
# Code Block 3: 风险评分引擎 (report.py)
def _compute_risk_score(findings, has_executable_scripts):
    score = 0
    for f in findings:
        sev = (f.severity or "LOW").upper()
        if sev == "CRITICAL":   score += 50
        elif sev == "HIGH":     score += 25
        elif sev == "MEDIUM":   score += 10
        elif sev == "LOW":      score += 5
    if has_executable_scripts:
        score = int(score * 1.3)
    score = min(100, max(0, score))
    # Bands: 81+ CRITICAL, 51+ HIGH, 21+ MEDIUM, 0+ LOW
```

## 经验沉淀

1. **LangGraph 并行分析器模式**: 当需要对输入做多维度独立分析时，应优先使用 LangGraph DAG 将分析器并行化，最后用 meta_analyzer 做加权融合。适用于安全扫描、代码审查、多维度评分场景。

2. **AgentDef 注册表模式**: 当需要支持多种异构 agent/工具的日志或配置解析时，应优先定义统一接口 + 注册表，每种实现在独立文件中。新 agent 只需添加一个文件，零改动核心逻辑。

3. **SARIF 输出标准**: 当构建任何静态分析工具时，应优先支持 SARIF 输出格式。它是 OASIS 标准，GitHub CodeQL、ESLint、Semgrep 都支持，可无缝集成 CI/CD 和 IDE。

4. **SQLite + DuckDB 双层存储**: 当构建本地分析工具时，应优先 SQLite 做事务存储 + DuckDB 做 OLAP 分析层。零配置、单文件、高性能。
