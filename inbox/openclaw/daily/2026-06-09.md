## 关键经验（4 条独立章节 + 10 条项目级 = 14 条「应优先」格式）

1. **当把平台能力本地化时，应优先用「SKILL.md 入口 + system-prompt.md 方法论真相源 + references/<harness>.md 平台映射 + built-in-skills/ 专项能力」四件套**（baoyu-design）
2. **当给 Agent 加质量门禁时，应优先用 reactive review guard（事后审查）而非 inline constraints**（guard-skills）
3. **当需要多用户隔离执行环境且规模未到 K8s 时，应优先用「单 Go 二进制 + Docker + Traefik + SQLite + bind-mount」最小栈**（sandboxd）
4. **当 skill 内容需要量化、可审计时，应优先在 SKILL.md 中显式引用已发表研究（GitClear 2025 / Spracklen USENIX Security '25）**（guard-skills + baoyu-design）
