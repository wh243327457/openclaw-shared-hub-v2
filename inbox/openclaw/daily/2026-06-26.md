### 3.1 baidu/Unlimited-OCR

**Stars: 8482 · License: MIT · Language: Python · Created: 2026-06-18**

#### 项目概述

百度推出的 Unlimited-OCR 是一个端到端的文档解析模型，主打"One-shot Long-horizon Parsing"——单次推理即可处理超长文档的 OCR 识别与结构化输出。它基于 DeepSeek-OCR 架构改进，支持单图、多图、PDF 三种输入模式，通过 SGLang 提供 OpenAI 兼容 API，支持流式推理和并发批处理。项目一周内获得超过 8000 星，是本周增长最快的仓库。

该项目的核心价值在于：
- **一次推理处理长文档**：无需分页切片再拼接，减少上下文丢失
- **双模式配置**：`gundam` 模式（640px + crop）适合复杂版面，`base` 模式（1024px）适合整页
- **自定义 logit processor**：通过 `DeepseekOCRNoRepeatNGramLogitProcessor` 抑制重复 n-gram，提升输出质量
- **生产级推理管线**：SGLang 服务 + 并发客户端，支持流式输出

```python
def collect_stream_silent(resp, output_file: str | None) -> dict:
    chunks = []
    token_count = 0
    first_token_time = None
    f = open(output_file, "w", encoding="utf-8") if output_file else None
    try:
        for raw_line in resp.iter_lines():
            if not raw_line:
                continue
            line = raw_line.decode("utf-8") if isinstance(raw_line, bytes) else raw_line
            if not line.startswith("data:"):
                continue
            data = line[len("data:"):].strip()
            if data == "[DONE]":
                break
            try:
                chunk = json.loads(data)
                delta = chunk["choices"][0]["delta"].get("content", "")
            except (json.JSONDecodeError, KeyError):
                continue
            if not delta:
                continue
            if first_token_time is None:
                first_token_time = time.time()
            token_count += 1
            chunks.append(delta)
            if f:
                f.write(delta)
    finally:
        if f:
            f.close()
    end_time = time.time()
    decode_time = (end_time - first_token_time) if first_token_time and token_count > 1 else 0
    return {"tokens": token_count, "decode_time": decode_time, "text": "".join(chunks)}
```

#### 架构/实现原理

Unlimited-OCR 的推理架构分为两层：

1. **模型层**：基于 DeepSeek-OCR 架构的视觉语言模型，通过 HuggingFace Transformers 或 SGLang 加载
2. **服务层**：SGLang 提供 OpenAI 兼容的 `/v1/chat/completions` 端点，支持流式输出和自定义 logit processor

关键架构决策：
- 使用 `no_repeat_ngram_size=35` + `ngram_window` 控制重复文本（OCR 常见问题）
- `gundam` 模式将图片缩放到 640px 并启用 crop，适合复杂表格/多栏版面
- `base` 模式使用 1024px 全图，适合单栏文档和多页 PDF
- 并发通过 `ThreadPoolExecutor` 实现，每个请求独立流式处理

```
用户输入 (图片/PDF)
    │
    ▼
PyMuPDF 转图片 (PDF→PNG @300dpi)
    │
    ▼
Base64 编码 → OpenAI 兼容消息格式
    │
    ▼
SGLang Server (model=baidu/Unlimited-OCR)
    │  ├── Custom Logit Processor (NoRepeatNGram)
    │  └── FA3 Attention Backend
    ▼
流式 Token 输出 → 写入 .md 文件
```

#### 项目概述

kage（影）是一个用 Go 编写的网站离线镜像工具。它通过 headless Chrome 渲染网页，等待页面完全加载后抓取 DOM 快照，然后剥离所有 JavaScript，将 CSS、图片、字体等资源下载到本地并重写链接。最终产物是一个完全静态、可在离线环境下浏览的网站副本。

	// 恢复上次中断的状态
	if c.cfg.Resume && !c.cfg.Refresh {
		if err := c.front.load(c.statePth); err != nil {
			c.logf("resume: could not load state: %v", err)
		} else if n := c.front.visitedCount(); n > 0 {
			c.logf("resume: %d pages already done", n)
		}
	}

	c.pool = browser.New(browser.Options{
		Headless:      c.cfg.Headless,
		Workers:       c.cfg.BrowserPages,
		Settle:        c.cfg.Settle,
		RenderTimeout: c.cfg.RenderTimeout,
		Scroll:        c.cfg.Scroll,
		ChromeBin:     c.cfg.ChromeBin,
		ControlURL:    c.cfg.ControlURL,
	})
	defer func() { _ = c.pool.Close() }()

	c.loadRobots(ctx)
	c.setupCrawlDelayLimiter()

	// 启动页面渲染 worker 和资源下载 worker
	var workers sync.WaitGroup
	for range max1(c.cfg.Workers) {
		workers.Go(func() {
			for j := range c.pageJobs {
				c.processPage(ctx, j)
				c.wg.Done()
			}
		})
	}
	for range max1(c.cfg.AssetWorkers) {
		workers.Go(func() {
			for j := range c.assetJobs {
				c.processAsset(ctx, j)
				c.wg.Done()
			}
		})
	}

	// 种子 URL
	c.enqueuePage(ctx, c.seed, 0)
	if c.cfg.FollowSitemap {
		c.seedSitemaps(ctx)
	}

	// 等待所有任务完成后关闭通道
	go func() {
		c.wg.Wait()
		close(c.pageJobs)
		close(c.assetJobs)
	}()
	workers.Wait()

	// 保存爬取状态（支持断点续爬）
	if c.cfg.Persist {
		if err := c.front.save(c.statePth); err != nil {
			c.logf("could not save resume state: %v", err)
		}
	}

	res := Result{Progress: c.stats.snapshot(), OutDir: c.outRoot, Failures: c.stats.recordedFailures()}
	if ctx.Err() != nil {
		return res, ctx.Err()
	}
	return res, nil
}

func Strip(doc []byte, opts Options) ([]byte, Report, error) {

#### 架构/实现原理

kage 的架构是一个经典的生产者-消费者模式，核心管线如下：

```
种子 URL
    │
    ▼
Frontier (BFS 队列) ──robots.txt──▶ 过滤
    │
    ▼
Page Worker Pool (N 个 Chrome tab)
    │  ├── headless Chrome 渲染
    │  ├── 等待页面 settle
    │  ├── 自动滚动（触发懒加载）
    │  └── DOM 快照
    ▼
sanitize.CleanTree()
    │  ├── 移除 <script> 标签
    │  ├── 移除事件处理器
    │  ├── 中和 javascript: URLs
    │  └── 移除 IE 条件注释
    ▼
Asset Worker Pool
    │  ├── 下载 CSS / 图片 / 字体
    │  ├── 重写 url() 引用
    │  └── 内容去重（SHA-256）
    ▼
写入磁盘 (确定性路径映射)
    │
    ▼
可选打包：ZIM / 自包含二进制 / 桌面应用
```

关键设计决策：
- **确定性路径映射**：每个 URL 映射到唯一的本地路径，避免重复下载
- **断点续爬**：通过 `state.json` 保存已访问集合，Ctrl-C 后可恢复
- **内容去重**：SHA-256 哈希检测相同内容，避免重复写入
- **robots.txt 遵从**：默认尊重 `robots.txt`，支持 `--no-robots` 覆盖
- **限速**：`rate.Limiter` 控制爬取速度，支持 `Crawl-delay` 指令

## 4. 经验沉淀

**当设计 Agent 工具接口时，应优先采用"文件即注册"模式。** Vercel eve 验证了这一设计：每个 `.ts` 文件导出一个 `defineTool()` 调用，文件名即工具名，编译器自动扫描目录完成注册。Hermes 的 `skills/` 目录已有类似机制，但可以更彻底——让 Skill 的定义、文档、测试都在同一个目录中自包含。

**当处理 OCR/文档解析任务时，应优先考虑"单次推理 + 自定义 logit processor"方案。** Unlimited-OCR 的核心创新不是模型架构，而是通过 `NoRepeatNGramLogitProcessor` 解决了长文档 OCR 中的重复文本问题。这提示我们：在 Agent 管线中，后处理策略（logit processor）往往比模型本身更重要。

**当需要离线保存网页时，应优先使用"渲染后剥离"而非"直接抓取"。** kage 的方法——先用 headless Chrome 渲染完整 DOM，再剥离 JS——是处理现代 Web 唯一可靠的方式。传统的 `wget`/`curl` 只能拿到 HTML 源码，对 SPA 和懒加载内容无能为力。

**当设计并发爬取系统时，应优先实现"确定性路径映射 + 断点续爬"。** kage 的 `urlx.LocalPath()` 将每个 URL 确定性地映射到本地路径，配合 `state.json` 持久化已访问集合，实现了优雅的幂等爬取。这一模式适用于所有需要遍历网络资源的场景。
