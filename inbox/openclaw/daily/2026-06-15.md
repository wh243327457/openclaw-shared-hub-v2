### 1. NVIDIA/SkillSpector

**一句话判断**: AI Agent skill 安全扫描的行业标准工具——用 LangGraph 并行分析管线替代人工安全审查，对任何使用 Claude Code / Codex CLI 的团队都是必备。

**解决的问题**: AI agent skill 以隐式信任执行，研究显示 26.1% 含漏洞、5.2% 有恶意意图。SkillSpector 用自动化静态 + LLM 分析填补 SAST 工具无法覆盖 prompt injection、MCP poisoning 的空白。

**架构/实现**:

SkillSpector 采用 **LangGraph StateGraph** 作为编排骨架：

1. `resolve_input` — 标准化输入（Git URL / zip / 目录 / 文件）→ 本地目录
2. `build_context` — 遍历目录，构建文件缓存、manifest、组件元数据
3. **16+ 分析器并行扇出** — 静态模式、行为 AST、语义、MCP 专检、YARA 签名
4. `meta_analyzer` — LLM 驱动的发现过滤与丰富
5. `report` — 生成 terminal/JSON/Markdown/SARIF 输出，含风险评分 0-100

```python
# graph.py — LangGraph 工作流定义
def create_graph():
    workflow = StateGraph(SkillspectorState)
    workflow.add_node("resolve_input", resolve_input)
    workflow.add_node("build_context", build_context)
    workflow.add_node("meta_analyzer", meta_analyzer)
    workflow.add_node("report", report)
    for analyzer_id in ANALYZER_NODE_IDS:
        workflow.add_node(analyzer_id, ANALYZER_NODES[analyzer_id])

    workflow.add_edge(START, "resolve_input")
    workflow.add_edge("resolve_input", "build_context")
    for analyzer_id in ANALYZER_NODE_IDS:
        workflow.add_edge("build_context", analyzer_id)
        workflow.add_edge(analyzer_id, "meta_analyzer")
    workflow.add_edge("meta_analyzer", "report")
    workflow.add_edge("report", END)
    return workflow.compile()
```

### 2. andrewyng/aisuite

**一句话判断**: Andrew Ng 出品的统一 AI 接口库，22 个 provider 一行切换——这是 Hermes provider 抽象层的最佳参考实现。

**解决的问题**: 每个 LLM provider 有独立 SDK、不同的参数命名和认证方式，切换模型需要改多处代码。aisuite 用 `<provider>:<model>` 字符串约定 + 动态加载消除了这种摩擦。

**架构/实现**:

两层架构：
1. **Chat Completions API** — 统一 OpenAI 风格接口，`ProviderFactory` 通过 `importlib` 按命名约定动态加载 provider
2. **Agents API** — Agent 数据类 + Runner 多轮工具调用循环 + ToolPolicy 治理 + MCP 集成

```python
# provider.py — 动态 provider 加载
class ProviderFactory:
    PROVIDERS_DIR = Path(__file__).parent / "providers"

    @classmethod
    def create_provider(cls, provider_key, config):
        provider_class_name = f"{provider_key.capitalize()}Provider"
        provider_module_name = f"{provider_key}_provider"
        module_path = f"aisuite.providers.{provider_module_name}"
        try:
            module = importlib.import_module(module_path)
        except ImportError as e:
            raise ImportError(f"Could not import {module_path}: {e}")
        provider_class = getattr(module, provider_class_name)
        return provider_class(**config)

    @classmethod
    @functools.cache
    def get_supported_providers(cls):
        provider_files = Path(cls.PROVIDERS_DIR).glob("*_provider.py")
        return {file.stem.replace("_provider", "") for file in provider_files}
```

### 3. shiyu-coder/Kronos

**一句话判断**: 首个开源金融 K 线基础模型（AAAI 2026），用 Binary Spherical Quantization 将连续 OHLCV 数据离散化为 token——这种方法论可迁移到任何需要"连续信号→离散 token"的场景。

**解决的问题**: 传统金融预测依赖手工特征工程（技术指标），Kronos 将 K 线序列视为"语言"，用 tokenizer + autoregressive Transformer 直接建模，免去手工特征。

**架构/实现**:

两阶段框架：
1. **KronosTokenizer** — Encoder-Decoder Transformer + Binary Spherical Quantization (BSQ)，将连续 OHLCV 数据量化为层级离散 token
2. **Kronos** — Decoder-only Transformer 自回归预测未来 token
3. **KronosPredictor** — 推理封装：归一化 → 批量预测 → 反归一化

BSQuantizer 是核心创新——用二值球面量化 + 可微分熵损失实现 codebook 高利用率。

```python
# model/module.py — Binary Spherical Quantizer 核心
class BinarySphericalQuantizer(nn.Module):
    def __init__(self, embed_dim, beta, gamma0, gamma, zeta, group_size=9):
        super().__init__()
        self.embed_dim = embed_dim
        self.group_size = group_size
        self.num_groups = self.embed_dim // group_size
        self.register_buffer('basis', 2 ** torch.arange(embed_dim - 1, -1, -1))

    def quantize(self, z):
        """Straight-through estimator for binary quantization."""
        zhat = torch.where(z > 0,
                           torch.tensor(1, dtype=z.dtype, device=z.device),
                           torch.tensor(-1, dtype=z.dtype, device=z.device))
        return z + (zhat - z).detach()  # straight-through gradient
```

class KronosTokenizer(nn.Module, PyTorchModelHubMixin):
    def __init__(self, d_in, d_model, n_heads, ff_dim, n_enc_layers, n_dec_layers, ...):
        super().__init__()
        self.embed = nn.Linear(self.d_in, self.d_model)
        self.encoder = nn.ModuleList([
            TransformerBlock(self.d_model, self.n_heads, self.ff_dim, ...)
            for _ in range(self.enc_layers - 1)
        ])
        self.decoder = nn.ModuleList([
            TransformerBlock(self.d_model, self.n_heads, self.ff_dim, ...)
            for _ in range(self.dec_layers - 1)
        ])
        self.quant_embed = nn.Linear(self.d_model, self.codebook_dim)
        self.tokenizer = BSQuantizer(self.s1_bits, self.s2_bits, beta, gamma0, gamma, zeta, group_size)

    def forward(self, x):
        z = self.embed(x)
        for layer in self.encoder:
            z = layer(z)
        z = self.quant_embed(z)
        bsq_loss, quantized, z_indices = self.tokenizer(z)

可微分熵损失 — 保证 codebook 利用率：

```python
class DifferentiableEntropyFunction(Function):
    @staticmethod
    def forward(ctx, zq, basis, K, eps):
        zb = (zq + 1) / 2
        zi = ((zb * basis).sum(-1)).to(torch.int64)
        cnt = torch.scatter_reduce(torch.zeros(2 ** K, device=zq.device), ...)
        prob = (cnt + eps) / (cnt + eps).sum()
        H = -(prob * torch.log(prob)).sum()
        return H

    @staticmethod
    def backward(ctx, grad_output):
        zq, zi, prob = ctx.saved_tensors
        grad_array = -grad_output * (torch.log(prob) + 1) / zi.numel() / ctx.K
        reord_grad = grad_array[zi.flatten()].reshape(zi.shape)
        grad_input = reord_grad.unsqueeze(-1) * zq
        return grad_input, None, None, None, None
```

KronosPredictor 批量推理 — 归一化 → 预测 → 反归一化：

```python
# Normalization
x_mean, x_std = np.mean(x, axis=0), np.std(x, axis=0)
x_norm = (x - x_mean) / (x_std + 1e-5)
x_norm = np.clip(x_norm, -self.clip, self.clip)

# Batch prediction
preds = self.generate(x_batch, x_stamp_batch, y_stamp_batch,
                      pred_len, T, top_k, top_p, sample_count, verbose)

# Denormalization
preds_i = preds[i] * (stds[i] + 1e-5) + means[i]
pred_df = pd.DataFrame(preds_i, columns=self.price_cols + [self.vol_col, self.amt_vol])
```

## 经验沉淀

1. **当构建多阶段分析管线时，应优先使用 LangGraph StateGraph + `Annotated[list, operator.add]` reducer**，因为它天然支持并行扇出和结果聚合，比串行 chain 更高效且代码更清晰。来源：NVIDIA/SkillSpector。

2. **当设计多 provider 抽象层时，应优先采用 `importlib` + 命名约定的动态加载模式**，因为它让新增 provider 只需一个文件，零配置即生效。来源：andrewyng/aisuite。

3. **当需要实现 agent 层级组合时，应优先用 `agent_tool()` 把子 agent 包装为可调用工具**，因为它支持 trace 传播和 context 透传，比直接函数调用更适合复杂编排。来源：andrewyng/aisuite。

4. **当处理连续信号的离散化时，应优先考虑 Binary Spherical Quantization**，因为它无需 codebook 训练且支持 straight-through 梯度。来源：shiyu-coder/Kronos。
