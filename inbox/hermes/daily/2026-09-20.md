## 3. 值得沉淀

1. “保存活动”和“抓款/刷新缓存”是两个独立动作；验证新价格类型必须覆盖 OS 保存、队列消费、Redis、ES、App 读取全链路。
2. 新类型复用旧链路时，不能只核对计算公式，还必须确认实际消费者版本支持新枚举，尤其避免共享队列被旧 worker 抢占。
3. Git worktree 不包含被忽略的 `.env`、runtime、缓存文件；动态路由命中目录不等于业务环境已经可运行。
4. PHP worktree 可以通过域名动态选择源码目录；Go 项目必须为每个 feature 启动独立实例，不能只靠 NGINX 切源码。
5. 高风险价格链路应坚持最小改动，并把“静态验证通过”和“真实接口/端到端通过”明确区分。
