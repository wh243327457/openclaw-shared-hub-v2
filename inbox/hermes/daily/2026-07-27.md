## 3. 值得沉淀

1. 全局图片向量只能判断“整张图更像什么”，不能可靠判断某类服装是否独占画面。
2. 清洗链路应采用“向量高召回 → GD/VLM 多目标存在性判断 → 高置信自动候选 → 冲突与低置信人工复核”。
3. 向量分差适合排序和分层抽样，不应直接作为删除条件。
4. 数据库清洗前应先输出可回滚的候选 ID 清单，并保持数据库查询阶段严格只读。
5. 本地 HTML 报表生成后必须做 JavaScript 语法和数据一致性验证，不能只验证文件存在。
