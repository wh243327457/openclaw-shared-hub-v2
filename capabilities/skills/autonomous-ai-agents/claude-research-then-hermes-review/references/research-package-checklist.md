# 首轮调研包验收清单

用于判断 Claude Code 交回的是否是“可复核研究包”，而不是不可追踪的普通总结。

## 1. 来源完整性
- [ ] 至少给出实际使用的 URL 清单
- [ ] 每个来源都有标题或来源名
- [ ] 每个来源都说明“为什么重要”
- [ ] 覆盖了任务要求的来源类型/数量

## 2. 证据可追踪性
- [ ] 关键结论能回溯到具体来源
- [ ] 至少给出关键摘录或关键启发
- [ ] 高影响断言有明确来源支撑
- [ ] 推断与事实已分开标注

## 3. 任务覆盖度
- [ ] 用户要求的必答问题都已覆盖
- [ ] 没有跳过关键比较项/冲突项
- [ ] 不确定处被显式标注
- [ ] 有未决问题/风险清单

## 4. 工作流真实性
- [ ] 没有只给概念性空话
- [ ] 没有省略 URL
- [ ] 没有把未核实内容写成确定事实
- [ ] 输出看起来像“研究包”，不是直接终稿

## 5. Hermes 二轮复核动作
- [ ] 先检查来源与结构是否完整
- [ ] 再抽查高影响断言的原文
- [ ] 若有冲突，写明裁决逻辑
- [ ] 若有缺口，优先定向返工 Claude Code
- [ ] 最终稿明确区分：来源事实 / 推导规则 / 未决问题
