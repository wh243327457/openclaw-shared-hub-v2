# 总控台式进度汇报检查清单

## 第一屏
- [ ] 第一屏先回答“现在什么情况”
- [ ] 首段控制在 2~3 句内
- [ ] 先给态势，再给过程

## 结构
- [ ] 已写明当前阶段
- [ ] 已写明完成度，并给依据
- [ ] 已写明人话结论
- [ ] 已写明下一步

## 风险表达
- [ ] 已标注在轨 / 有风险 / 失轨
- [ ] 若存在 blocker，已写清：卡点 / 影响 / 处理路径 / 是否需用户介入
- [ ] 若无 blocker，明确写“暂无关键阻塞”

## 用户可决策性
- [ ] 用户看完前 3~5 行就能知道当前状态
- [ ] 已写明是否需要用户动作
- [ ] 下一步具体到动作与预期输出

## 文案质量
- [ ] 以中文短句表达
- [ ] 没有把原始 todo 当正文
- [ ] 没有贴长日志、长英文句、内部状态流
- [ ] 如需细节，已给详情入口
